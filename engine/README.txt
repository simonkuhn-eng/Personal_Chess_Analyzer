STOCKFISH ENGINE DIRECTORY
============================
Place your downloaded Stockfish executable in this directory as:
stockfish.exe

Download Stockfish for Windows:
https://stockfishchess.org/download/
(Select the Windows version suitable for your CPU, e.g., 'Stockfish 17 - Windows x86-64-avx2')

The application will automatically detect engine/stockfish.exe on startup!
You can also select any custom location inside the application settings.
